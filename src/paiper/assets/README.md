# Packaged typography

These unmodified Latin WOFF2 files are bundled for offline rendering. No font
service is contacted at runtime. Both families are licensed under SIL Open Font
License 1.1; the complete licenses and copyright notices are included alongside
the fonts.

Downloaded 2026-10-26 from the official Google Fonts distribution, using
[its CSS API](https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@6..72,400&family=Public+Sans:wght@400..600&display=swap)
with a Chromium user agent to select WOFF2.

The stillness scene uses the public-domain World English Bible excerpt
“Be still, and know that I am God.” (Psalm 46:10), credited on the frame.
Source: [World English Bible, Psalm 46](https://ebible.org/engwebp/PSA046.htm).
The masthead's **Updated** value is the image-generation time in
`America/Chicago` (with a date and DST-aware zone abbreviation), not a live clock.
